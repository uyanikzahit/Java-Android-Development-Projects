# Java Android Development Projects

A curated collection of **Android projects and feature-focused samples built with Java**.  
This repository is organized as a learning and reference hub for Android fundamentals, UI/UX components, persistence, networking, architecture patterns, and testing.

> The projects are grouped by topic so you can quickly open a folder, run the sample, and learn a focused concept.

---

## What You’ll Find in This Repository

This repository includes Android Java samples covering:

- **UI & Animations**
  - Animations, MotionLayout, Material Design, Floating Action Button (FAB) animations
- **Navigation & Layout**
  - Navigation Component, TabLayout, screen flows
- **Persistence**
  - SQLite samples, **Room** usage and patterns
- **Architecture & Patterns**
  - **MVVM** sample(s), modular project structure
- **Dependency Injection**
  - **Dagger** usage sample(s)
- **Networking & Data**
  - Volley samples, JSON parsing samples
- **Firebase**
  - Firebase practice modules (Realtime Database / Push Notifications samples)
- **Device Features**
  - Location usage sample(s), notifications
- **Testing**
  - Espresso UI testing, unit testing samples
- **Mini Apps**
  - Simple apps like number guessing, progress/seek/rating bar usage, drag & drop samples


---

## How to Run

### Prerequisites
- **Android Studio**
- Android SDK installed
- Java / JDK configured by Android Studio
